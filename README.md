## What it does

`main.ts` writes a single-line joke giving an excuse for a missed deadline to `/output/entry.txt`. The program is fully deterministic: it writes the same line on every run, with no clock, network, or random input.

The joke:

> I treated the deadline like a gym membership — paid for it, admired it from afar, and never actually showed up.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt` (override the path with `OUTPUT_PATH` for local testing).
